# Projeto de Banco de Dados

**Nome do projeto**:  Sistema de Postagens e Comentários 
**Equipe de Desenvolvimento**:  Felipe


## 1.Visão  Geral  do Sistema (Escopo)
O sistema deseja permitir que os usuários realizem postagens e possam fazer comentário em uma rede social

## 2.Requisitos Funcionais(RF)
**RF01**: O sistema deve gerenciar o cadastro de seus usuários, as informações úteis que foram levantados são:

 - Nome do usuário
 - e-mail
 - senha
 - idade

**RF02**: O sistema deve permitir que o usuário possa criar, editar e excluir suas ponstagen, será nescessário que contenha os seguintes campos:

 - Nome do usuário
 - data e hora da publicação
 - adicionar texto
 - adicionar figurinhas

**RF03**: O sistema deve permitir que o usuário possa fazer comentários nas ponstagen, contendo os seguintes campos:

 - Nome do usuário
 - data e hora do comentário
 - adicionar texto
 - adicionar figurinhas
